# Open Web Monitor

Web ページ全体または CSS セレクターで指定した部分の変更を監視する、独立実装の Chrome 拡張です。登録件数に固定の上限はありません。データは `chrome.storage.local` に保存され、サーバーやアカウントは不要です。

## インストール

1. Chrome で `chrome://extensions` を開きます。
2. 「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダーを選びます。
4. 拡張機能のアイコンをクリックして、ページ全体またはページ内の部分を監視に追加します。監視一覧から URL を直接登録することもできます。

更新後は `chrome://extensions`（Brave では `brave://extensions`）でこの拡張機能の「再読み込み」を押してください。

## 機能

- ページ全体、またはクリックして選んだ複数の要素を CSS セレクターで監視
- 要素選択パネルで除外する要素を指定し、保存前に抽出テキストをプレビュー
- 監視対象を緑枠、無視対象を赤枠でページ上に表示。クリックした要素のクラス・ID・親要素から CSS セレクター候補を選択可能
- 要素選択画面で監視 URL を編集し、変更先のページを開いてプレビュー。選択を保存すると編集画面が開き、タグと確認間隔を続けて設定可能
- 内容の要約を並べて確認できるコンパクトなリスト型 Watchlist
- Watchlist の項目を複製（設定を引き継ぎ、履歴と前回の取得内容は新規に開始）
- 監視の設定を複数の URL に一括複製。登録済み URL はスキップし、初回確認で各ページのタイトルを名前に反映
- 左側の「すべて・未読・エラー・ごみ箱・タグ別」から表示を切り替え。各画面の表示中リンクをまとめて新しいタブで開くことが可能
- 編集画面でタグを作成して複数付与。ごみ箱からの復元と完全削除に対応
- 検索・並び替え、ポップアップで現在のページの登録済み監視を表示
- 行のチェックボックスと「すべて選択」で監視を選び、確認間隔とタグの追加・解除をまとめて編集
- 1 分〜 1 週間の間隔で自動確認。編集画面では分・時間・日と、15 分／1 時間／6 時間／1 日／7 日の選択ボタンを利用可能
- 監視時の開き方を「非アクティブな一時ピン留めタブ」または「新しい非アクティブウィンドウ」から選択可能。取得後は自動で閉じます
- 監視ごとにON/OFFできる変更通知。通知をクリックすると監視先ページを開いて既読にします。未読バッジと各監視につき直近 30 件の変更履歴
- 独立した設定画面で監視時の開き方と同時確認数を設定。タグとごみ箱を含む JSON エクスポート・インポート
- 件数上限なし（実際の処理量は PC、Chrome、サイトの応答速度に依存）

## 動作上の注意

- Chrome が起動している間に確認します。初期設定では非アクティブなピン留めタブを短時間開きます。新しいウィンドウ方式はウィンドウを一時的に作るため、サイトの表示や OS によって挙動が異なる場合があります。
- 同時確認数は設定画面から変更できます（初期値 4 件）。定期処理ごとの件数上限はなく、期限に達した監視を設定件数ずつ順次確認します。
- ページの最初の 100,000 文字を比較し、連続する空白の違いは無視します。ログイン状態・動的表示・読み込みタイミングに依存するページでは、結果を確認してください。
- メール、SMS、クラウド同期、JavaScript/XPath 抽出は現時点ではありません。設定のエクスポートには履歴やページの取得内容は含まれません。
- 全 Web サイトへのアクセス権は登録済み URL の定期確認に使用します。データは外部に送信しません。

## 開発時の確認

`npm test` で URL、間隔、テキスト比較の単体テストを実行し、`npm run check` で JavaScript の構文を確認します。
